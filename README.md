# Spam Classification

Spam vs. ham email classification with a full data-quality workflow: missing value analysis, feature engineering, outlier detection (IQR method), before/after outlier removal comparison, and a TF-IDF + Naive Bayes classifier.

**Dataset:** Enron-Spam email corpus (real corporate emails), sampled to a 60/40 ham/spam split.

**Notebook:** `spam_classification.ipynb` — run end to end, all outputs saved inline.
